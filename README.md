# FRC-Make-your-robot-better-Magic-Wand-
FIRST Robotics-themed magic wand. 

# Why am I making this?
This wand is meant to give other teams something fun at FRC events (basically like a friendship bracelet, but it's a wand! lol).
This wand is not finished yet because I have been busy, but I plan to get it done before FTC kickoff so it can not only be used by FRC teams to give out in the pits but also by FTC teams!
